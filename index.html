remdetect causal REM sleep detector

A real-time-valid REM detector for a closed-loop lucid-dream project, benchmarked on expert-scored Sleep-EDF polysomnography. Every feature and decision for epoch t uses only epochs 0..t, because at 4 a.m. the system only has the past.

  • Causal by construction, enforced by test. Expanding-window normalisation, lag-only features, and a forward-only state machine with hysteresis. A causality test destroys future data and asserts past outputs are bit-identical.
  • Subject-wise cross-validation. GroupKFold on subject ID so the same sleeper never appears in train and test. EEG is close to a biometric; mixing subjects inflates scores and means nothing.
  • A locked holdout that makes self-fooling a deliberate act. Deterministic hash-based dev/test split, and every test-set run is appended to an audit log with a config hash. If the audit shows one config, the number is clean. If it shows nine, the tool says so.
  • Reports the failing configuration too. The wearable-realistic EEG-only setup misses the false-positive target on real data. That result is left in and diagnosed, not tuned away.

crypto-grid-bot risk-gated grid trading

A grid-trading bot for the Crypto.com Exchange (ADA/USDT) with a paper-trading simulator on live prices, a web dashboard, Telegram alerts and commands, crash-safe SQLite state reconciliation, and a backtester that was built to prove the strategy wrong before trusting it.

  • Hard risk rules, not vibes. A reserve floor that keeps both assets above a share of equity even during emergency exits, a 100-day trend gate that parks the bot in cash below trend, a daily loss limit, per-order size caps, and a crash-floor stop.
  • Walk-forward backtest that killed the headline number. Cross-checking the fast backtester against the production Decimal engine caught two bugs (a re-armed buy not reserving cash, a sell not removing inventory) that had inflated returns 5 to 10x. Both are pinned as regression tests.
  • Honest out-of-sample reporting. Parameters were swept on a train window and re-evaluated on a held-out test window. The README says plainly where the strategy still trails buy-and-hold and why grid trading caps upside in a strong uptrend.
  • Trend gate result in walk-forward tests: max drawdown 64% to 23%, bear-phase return from -28% to +18%.

kovaaks-team-tracker self-hosted stats and coaching site

Ingests KovaaK's aim-trainer run files from every player on my six-person team, normalises them against Voltaic benchmarks, and tells each player what to train next. Live at aim.xebyte.com, with a companion Windows desktop client written in Go that syncs runs automatically.

  • Security review before first deploy, with regression tests. Cross-origin request forgery protection that goes beyond SameSite because the host shares a domain with about 30 other services. Startup refuses an unsafe production config rather than trusting the operator to flip a flag.
  • Fixed a real zip-bomb path. Upload expansion was capped after the list was built, so the cap protected nothing. Bounds now apply during the walk and the read goes through a size-limited stream, so a member that lies about its size costs a buffer, not its true size.
  • Desktop sign-in hardened. The OAuth loopback port is bound to the OAuth state, and the Go client rejects any callback whose nonce doesn't match under a constant-time compare.
  • Boring reliability. CI on every push, a migration-drift test that fails when models and Alembic disagree, a pinned dependency lockfile, off-box nightly database backups, and Discord announcements that can't be turned into a server-wide ping by a crafted scenario name.
